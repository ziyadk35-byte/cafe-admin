# لوحة تحكم الكافيه (Admin Panel)

تطبيق ويب (React + Vite) لإدارة الفروع والمنتجات ومتابعة الطلبات.

## 1. التثبيت
```
cd cafe-admin
npm install
```

## 2. ربطها بالباك اند
افتح `src/api/client.js` وغيّر:
```js
export const API_BASE_URL = 'http://localhost:5000/api';
```
لعنوان السيرفر الحقيقي بعد النشر.

## 3. التشغيل محليًا
```
npm run dev
```
هيفتح على `http://localhost:5173`

## 4. تسجيل الدخول
لازم يكون عندك مستخدم بدور `admin` في قاعدة البيانات. أسهل طريقة تعمليها:
- سجّل حساب عادي من تطبيق الموبايل (customer)
- ادخل على MongoDB (عن طريق MongoDB Compass أو Atlas) ولاقي المستخدم ده في collection اسمها `users`
- غيّر الحقل `role` من `customer` لـ `admin` يدويًا

## 5. النشر (Deployment)
```
npm run build
```
ده هينتج مجلد `dist` تقدر ترفعه على أي استضافة ستاتيك (Vercel, Netlify) أو تحطه على نفس الـ VPS بتاعك خلف Nginx زي أي موقع static.

مثال إعداد Nginx لتقديم اللوحة من نفس السيرفر:
```
server {
    listen 80;
    server_name admin.your_domain.com;
    root /home/username/cafe-admin/dist;
    index index.html;
    location / {
        try_files $uri /index.html;
    }
}
```

## ملاحظات
- الصلاحيات محمية من الباك اند نفسه (`restrictTo('admin')`) — حتى لو حد فتح اللوحة، مش هيقدر يعدل حاجة من غير حساب أدمن حقيقي.

## المميزات المضافة
- **الموظفين**: إضافة كاشير/دليفري لأي فرع مباشرة من اللوحة (بيتفعّل فورًا من غير OTP)
- **الكوبونات**: إنشاء أكواد خصم بنسبة مخصصة، بتاريخ انتهاء، وحد أقصى للاستخدام
- **التقارير**: إجمالي المبيعات، عدد الطلبات، متوسط قيمة الطلب، المبيعات حسب الفرع، والأكتر مبيعًا — لأي فترة تحددها
- **فتح/قفل الفرع مؤقتًا**: من صفحة الفروع، تقدر توقف استقبال طلبات فرع معين مؤقتًا (يوم إجازة، أو مشغول جدًا) من غير ما توقفه نهائيًا
- **تصنيف المنتجات**: كل منتج بقى له تصنيف (سخن / ساقع / أكل) — ده اللي بيحدد الفلاتر في تطبيق العميل
- **العروض**: من صفحة المنتجات، تقدر تفعّل "عرض" على أي منتج وتحدد سعر مخفض — المنتج ده هيظهر تلقائيًا في تاب "عروضنا" في التطبيق
- **فلترة الموظفين حسب الفرع**: من صفحة الموظفين، تقدر تعرض بس موظفي فرع معين

## صلاحيات الكاشير والدليفري
- **الكاشير (branch_staff)** بيشوف طلبات فرعه بس، وهو اللي بيعيّن الدليفري المناسب لكل طلب (من الدليفريز الشغالين في نفس الفرع) لحظة ما الطلب يبقى جاهز للتوصيل.
- **الدليفري** بيشوف طلب واحد بس — اللي معيّن ليه حاليًا — وأول ما يتعيّنله طلب، موقعه بيتبعت لحظيًا للكاشير وللعميل تلقائيًا من غير أي إعداد يدوي. الشاشة بتاعته فيها زرار واحد بس: "تم التوصيل".
- **الأدمن** هو الوحيد اللي يقدر يعمل حسابات كاشير/دليفري جديدة، وهو الوحيد اللي شايف كل الموظفين في كل الفروع من لوحة التحكم.
- **رفع صور المنتجات مباشرة**: من صفحة المنتجات، دلوقتي تقدر ترفع صورة من جهازك مباشرة بدل ما تلزق رابط — بتترفع تلقائي لـ Cloudinary وترجع لك رابطها. محتاج تتأكد إن بيانات Cloudinary (`CLOUDINARY_CLOUD_NAME` وغيرها) متظبطة في ملف `.env` بتاع الباك اند، بنفس الطريقة الموضحة في `README.md` بتاع الفرونت اند.
